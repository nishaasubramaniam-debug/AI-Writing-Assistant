# 🤖 AI Writing Assistant

A professional AI-powered web application built using **Python**, **Streamlit**, and **Google Gemini**.

## Features

- 📧 Professional Email Generator
- 📝 AI Text Summarizer
- 🤖 Powered by Google Gemini
- 🎨 Modern Streamlit UI

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
